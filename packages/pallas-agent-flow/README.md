# Pallas Agent Flow

Pallas Agent Flow is the orchestration package for turning project requirements into
technical specs, Ponytail-reviewed packets, parallel implementation worktrees, and
targeted recovery.

- Repository: https://github.com/semper-nova-tech/pallas-agent-flow
- Pinned ref: `eea1de8`
- Install location: `$PALLAS_AGENT_FLOW_HOME` or `$HOME/tools/pallas-agent-flow`
- Cursor integration: `~/.cursor/plugins/local/pallas-agent-flow`
- Recommended preset: `cursor.simple`

It is installed by default with the lore installer:

```bash
./install.sh /path/to/repo
```

Use `--without-pallas-agent-flow` to skip it.

An existing Pallas Agent Flow checkout or Cursor plugin link is left unchanged. Update
those separately with the repository's normal Git workflow.
